# Streamlabs chat styles

**Live preview:** https://demusenko-n.github.io/showcase-profiles-streamlabs-chat/

Custom styles for the Streamlabs Chat Box widget. Each top-level folder is one style
(`chat.html`, `chat.css`, `chat.js`, `fields.json`). To use a style, paste these files into the
HTML, CSS, JS and Fields tabs of the widget's custom code editor.

The preview page loads every style straight from this repository, lets you tweak its fields,
upload your own background and drag the chat frame to get the coordinates for OBS.
